# biom5350-seq-tools

A Python tool for calculating GC and AT content from sequences in a FASTA file.

## Usage

```bash
python gc_content.py example.fasta
```

The script prints each sequence name, length, GC percentage, and AT percentage, followed by the mean GC percentage across all sequences. Ambiguous bases are included in the length and excluded from the GC and AT percentages.
